# Documentación del Proyecto Bot Sandbox de Nexo.ia

Este documento proporciona una visión general del proyecto Bot Sandbox de Nexo.ia, incluyendo su estructura, componentes principales y guía de implementación.

## Estructura del Proyecto

El proyecto Bot Sandbox de Nexo.ia consta de los siguientes componentes principales:

1. **Interfaz de Cliente (Sandbox)**
   - Entorno de pruebas para que los clientes interactúen con sus bots
   - Formulario de feedback para enviar comentarios
   - Interfaz personalizada para cada cliente

2. **Panel de Administración**
   - Sistema de gestión de clientes y sandboxes
   - Asignación de scripts de bot
   - Monitoreo de feedback y actividad

3. **Sistema de Notificaciones**
   - Integración con Gmail para envío de emails
   - Notificaciones automáticas a clientes

## Guía de Implementación

### Requisitos del Servidor

- Servidor web (Apache o Nginx)
- PHP 7.4 o superior
- MySQL 5.7 o superior
- Certificado SSL (recomendado)

### Pasos de Instalación

1. **Configurar el servidor web y la base de datos**
2. **Subir los archivos al servidor**
3. **Importar la estructura de la base de datos**
4. **Configurar los parámetros en config.php**
5. **Configurar los dominios y subdominios**

Para instrucciones detalladas, consulte la guía de implementación completa incluida en este paquete.

## Componentes Incluidos

- **bot-sandbox**: Interfaz básica del sandbox para clientes
- **admin-sandbox**: Panel de administración completo
- **script-assignment-demo**: Demostración de asignación de scripts
- **documentación**: Guías y manuales de uso
