Guía: Cómo asignar scripts de bot a los clientes
1
Seleccionar un cliente

En el panel izquierdo, haz clic en el cliente al que deseas asignar un script de bot.

2
Ir a la pestaña "Script de Bot"

Una vez seleccionado el cliente, haz clic en la pestaña "Script de Bot" para acceder al editor de scripts.

3
Pegar el código del script

Pega el código del script generado en SendPulse en el área de texto. El formato debe ser similar a:

<script src="https://cdn.pulse.is/livechat/loader.js" data-live-chat-id="XXXXXXXXXXXXXXXX" async></script>
4
Guardar el script

Haz clic en el botón "Guardar Script" para asignar el script al cliente seleccionado.

5
Verificar la vista previa

Ve a la pestaña "Vista Previa" para comprobar cómo se verá el sandbox del cliente con el script asignado.

6
Enviar la URL al cliente

Una vez verificado que todo funciona correctamente, envía la URL única del sandbox al cliente para que pueda probar su bot.
